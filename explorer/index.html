Extra args ❓
Extra dyno-sv command-line args, applied on every run.
  • -h, --help: print help
  • -d, --debug: run passes in debug mode
  • --debug-passes=<pass>: debug named passes (repeatable)
  • -X, --Xslang=<arg>: slang args (repeatable)
  • --only=<test>: only run listed tests (repeatable)
  • --print-after-all: print IR after all passes (test mode only)
